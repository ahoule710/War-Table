# Changelog

Each release's notes come from its section here. The app shows them under "What's new".

## 1.2.0
- Auto-updates: War Table checks this repo for new releases and installs them in one click. Every download is checked against its published SHA-256 before it's used.
- Updates section in Settings with "Check now".

## 1.1.0
- App icon, and a tray icon whose tooltip shows the weekly reset countdown. Left-click shows or hides the War Table; right-click for Move to next screen and Quit.
- Class themes: Warrior (Forge), Shaman (Tidecaller), Fire Mage (Pyre), each with its own colors, fonts, Vault slot shapes and ambient effects.
- Hover tooltips across the app. Ambient effects can be turned off in Settings.

## 1.0.7
- The Week tab always shows the current week, starting from zero after reset. Last week's data is kept but not shown.
- Fixed the Week tab going blank when WoW saved an empty list.

## 1.0.5
- Item level and stats no longer get replaced by blank snapshots taken during logout.

## 1.0.4
- Fixed duplicate characters caused by two spellings of the same realm.
- The setup card updates as soon as the API key is saved.

## 1.0.2
- Screen picker in Settings to open the War Table on another monitor.

## 1.0.1
- Fixed "127.0.0.1 refused to connect" on launch. Chrome is used for the window, with Edge as a fallback.

## 1.0.0
- First version: overlay window, Companion addon, Week, Spec and Ask tabs.
